# Kuwait Fines Bot | بوت مخالفات الكويت

نظام ويب متكامل للاستعلام عن المخالفات المرورية في دولة الكويت، مصمم ليطابق واجهة وزارة الداخلية الكويتية الرسمية.

## المميزات
- **تصميم مطابق**: واجهة مستخدم نسخة طبق الأصل من موقع وزارة الداخلية الكويتية.
- **استعلام دقيق**: جلب المخالفات للأفراد والشركات باستخدام الرقم المدني.
- **دعم الدفع**: واجهة لمحاكاة عملية الدفع وتجميع المخالفات المختارة.
- **لوحة تحكم**: لوحة إدارة لمتابعة عمليات الاستعلام والدفع.

## التقنيات
- **Frontend**: React + Vite + Tailwind CSS + Bootstrap (Kuwait MOI Theme).
- **Backend**: Node.js + Express + tRPC.
- **Database**: MySQL via Drizzle ORM.
- **Scraper**: Axios based scraper for Kuwait MOI API.

## التشغيل المحلي
1. قم بتثبيت التبعيات:
   ```bash
   pnpm install
   ```
2. قم بضبط متغيرات البيئة في ملف `.env`.
3. ابدأ تشغيل المشروع:
   ```bash
   pnpm run dev
   ```

## ملاحظة
هذا المشروع مخصص للأغراض التعليمية وتسهيل الوصول للمعلومات العامة من خلال الواجهات الرسمية.

تم تحديث الواجهة الأمامية (Frontend) لتطابق بدقة تصميم موقع وزارة الداخلية الكويتية، مع إصلاح مشاكل التجاوب (Responsiveness) وتنسيق القوائم الجانبية وشريط التنقل.
